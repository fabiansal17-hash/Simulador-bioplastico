# Simulador de Bioplástico — Olimpiadas STEM Bogotá 2026

Aplicación web estática para comparar un modelo de producción de bioplástico a partir de amero de maíz y lengua de vaca (*Rumex obtusifolius*).

## Publicar con GitHub Pages

1. Crea un repositorio nuevo en GitHub.
2. Sube `index.html` y `.nojekyll` a la raíz del repositorio.
3. En **Settings → Pages**, selecciona **Deploy from a branch**.
4. Selecciona la rama `main` y la carpeta `/ (root)`.
5. Guarda. GitHub generará una URL pública para compartir.

El simulador no requiere servidor, base de datos ni instalación.
